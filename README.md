# 4th-application
The NetworkDesign program demonstrates the use of Prim’s Algorithm to design a Minimum Cost Spanning Tree (MST) for a given undirected, connected, weighted graph.

In a network (such as computer networks, road systems, or communication links), there are often multiple possible connections between nodes, each with a certain cost. The goal is to connect all nodes with the minimum total cost, without forming any cycles — this is exactly what a Minimum Spanning Tree achieves.
